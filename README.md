## 那些冷门节点到底有没有用

冷门节点是我愿意长期留着 TAG 的主要原因，同时也是最容易被写过头的地方。

非洲、南美和一些小众地区距离远，延迟通常会高于香港、日本和新加坡。我不会拿它们当日常主力，也不会因为列表很长就挨个使用。它们更像是在明确需要某个地区时，订阅里刚好有一条路可以试。

如果你从来没有这类需求，两百多个节点只会让列表显得很热闹。最后常用的可能仍然只有三五条，那就没必要单纯为了数量多付钱。

## TAG机场有哪些让我不满意的地方

第一是价格。只需要几个热门地区，又没有流媒体和特殊落地需求，很容易找到更便宜的选择。

第二是节点太多以后需要自己整理。刚导入订阅时，长长一列看着很丰富，常用的还是那几条。花一点时间固定下来，体验会好很多。

TAG 给我的感觉一直很明确。它的长处是选择多，短处也是选择多。知道自己需要什么地区的人会觉得方便，只想点开就用的人可能嫌麻烦。
